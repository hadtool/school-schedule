🔒 Privacy Policy

Последнее обновление: январь 2025 · ЖадвалSoft

Коротко: Мы не собираем никаких личных данных. Все данные хранятся только в вашем браузере (localStorage) и никуда не отправляются.
✅ Главное

📋 Какие данные мы собираем?

Никаких. ЖадвалSoft — это статический сайт, размещённый на GitHub Pages. У нас нет сервера, нет базы данных, нет backend-а.

Все данные которые вы вводите (классы, предметы, учителя, расписание) сохраняются исключительно в localStorage вашего браузера на вашем устройстве.

🍪 Cookies и трекеры

Мы не используем:

  • Cookies для отслеживания
  • Google Analytics или другие системы аналитики
  • Рекламные трекеры
  • Пиксели социальных сетей

Единственное хранилище — localStorage вашего браузера, которое используется для сохранения введённых данных между сессиями.

🌐 GitHub Pages

Сайт размещён на GitHub Pages (github.io). GitHub может собирать базовую техническую информацию (IP-адрес, тип браузера) в своих логах согласно Privacy Policy GitHub.

Мы не имеем доступа к этим данным и не управляем ими.

🗑️ Как удалить данные?

Чтобы удалить все сохранённые данные приложения:

  • Откройте приложение → нажмите кнопку 🗑️ в шапке
  • Или: откройте DevTools браузера (F12) → Application → Local Storage → удалите запись sched_v4
  • Или: очистите данные сайта в настройках браузера

👶 Дети и персональные данные

Приложение предназначено для администраторов школ (взрослых). Мы рекомендуем не вводить полные персональные данные учеников — используйте только имена классов (5А, 6Б) и имена/инициалы учителей.
